# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in alma, please report it through
[GitHub's private vulnerability reporting](https://github.com/inf0-dev/alma/security/advisories/new)
rather than opening a public issue.

We will acknowledge receipt within 48 hours and aim to provide a fix or mitigation within 7 days for confirmed vulnerabilities.

## Scope

Security issues we care about include (but not limited to):

- Cross-site scripting (XSS) in rendered HTML output
- Injection vulnerabilities in document parsing
- Path traversal in file handling
- Denial of service through crafted input documents
